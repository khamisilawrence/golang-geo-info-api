# Country data

`countries.json` is the dataset the API serves. It is embedded in the binary, so the API has no runtime dependency on a third-party service.

It is generated by `go run ./scripts/build-countries` from two open datasets, merged by ISO 3166-1 alpha-2 code and pinned to specific commits in the script:

| Source | Fields used | Licence |
| --- | --- | --- |
| [mledoze/countries](https://github.com/mledoze/countries) | names, alternative spellings, ISO code, capital, area, languages, currencies | [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/) |
| [dr5hn/countries-states-cities-database](https://github.com/dr5hn/countries-states-cities-database) | population, time zones | [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/) |

`countries.json` is a derivative database of these sources and is made available under the [Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Flag images are linked from [flagcdn.com](https://flagcdn.com/), not stored here.

Population figures come from the source dataset and are approximate.
